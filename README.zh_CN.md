# Gold Digger（淘金者）

为 FoloToy AI Passport（ESP32-C3，240x320，三个按键）制作的原创挖矿 Roguelite。
架构与 Spartan 相同：游戏规则是 `core/` 中的可移植 C 代码，
`platforms/passport/main/ui/` 中的 Passport LVGL 界面是唯一的界面；
之后的桌面版与安卓版将通过 `platforms/common/` 的宿主适配层复用它。金币是唯一货币。

## 玩法

每次下井都会生成一座新矿井（宽 8 格、深 400 米）。向左、右或向下挖掘，收集矿石，
然后拉绳回到地面把矿石卖成金币。

- **能量**：每挥一次镐消耗 1 点能量。能量耗尽会昏倒：你会被救上来，但矿袋损失一半。
- **岩层**：泥土、黏土、石头、花岗岩、玄武岩、黑曜石，用初始镐分别要敲 1 到 6 下。
  镐每升一级，每层少敲一下，最少 1 下。正在敲的格子会出现裂纹。基岩和岩浆永远挖不动，
  会标红色 ✕。
- **矿石**：煤、铜、银、金、红宝石、钻石，越深越稀有、越值钱。宝箱直接给金币；
  基岩上还躺着两个遗物宝箱。
- **危险**：毒气袋消耗能量，矿灯 3 级才能看见。110 米以下的洞穴底部有岩浆：
  不能走到岩浆旁边，但挖穿洞穴可能让你掉进去，此时矿袋全部损失。坠落超过 3 米会消耗能量。
- **交易站**：镐（减少敲击次数）、矿灯（照明范围，3 级显示毒气）、体力（能量）、矿袋（容量）、幸运护符（每级矿石价值 +5%）、
  炸药（炸开身边 3x3 并收集矿石）。
- **电梯**：每 50 米一站。到达该深度后可以一次性购买该站，之后下井可从那里出发。

## Passport 按键

| 位置 | UP | DOWN | OK | 长按 OK |
| --- | --- | --- | --- | --- |
| 营地 / 菜单 | 上一个 | 下一个 | 选择 | 返回 |
| 矿井 | 向左挖/走 | 向右挖/走 | 向下挖 | 暂停（炸药、拉绳上井） |

按住 UP 或 DOWN 会连续移动。每次下井结束和购买后自动存档，在矿井中每 20 秒存档一次。
闲置时先调暗屏幕，然后存档并进入深度睡眠（设置 → Sleep when idle）；任意按键唤醒，
唤醒用的那一下不会被当作操作。连接 USB 供电时只关屏，不睡眠。

## 目录

```
core/                    规则、地图生成、存档格式（纯 C11）
tests/core_tests.c       core/ 的宿主测试
platforms/passport/      固件：BSP 组件、main/（存储、音频、ui/）
platforms/common/        宿主运行时与 ESP-IDF/BSP 适配头（目前用于无界面冒烟测试）
```

## 构建

宿主测试：

```bash
python tools/run_host_tests.py
```

固件（已激活 ESP-IDF 5.5.3）：

```powershell
tools/build-passport.ps1
```

生成 `build/passport/GoldDigger.bin` 与合并镜像 `GoldDigger-full.bin`。
烧录需要你的明确同意（串口与数据影响），不属于构建步骤。
